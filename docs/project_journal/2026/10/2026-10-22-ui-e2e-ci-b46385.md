# Deterministic Native UI E2E And Runner Validation

## Scope And Acceptance
- Follow the macOS repair in [PR #78](https://github.com/Joey-Project/tvOS-net-player/pull/78), based on master `203a904b8e318559126bddcfb513555f8bcbd142`.
- Add dedicated macOS/tvOS XCUITest targets and shared schemes, separate from existing unit/hosted-view suites. Exercise visible controls, not view-model calls.
- This journal describes the squash-merge target-branch result. Exact-head CI, GitHub Codex review, all resolved conversations and workflow CODEOWNER approval are merge requirements recorded in [PR #79](https://github.com/Joey-Project/tvOS-net-player/pull/79). No local review lane or protection bypass is used.
- Both new UI jobs are acceptance criteria even before their names are added to branch-protection settings. Nonzero passed target tests, zero failures and zero skips are required; compilation or simulator inventory alone never proves UI execution.

## Design
- Run the real Rust LAN cache server on loopback, with isolated state, a generated silent 92-second H.264 MP4 and 55 entries crossing the 50-item catalog boundary. Preserve gRPC control and HTTP Range media paths.
- Disable fixture Bilibili workers, login sessions, Bonjour and remembered-server autoconnection. Debug test apps use isolated preferences and per-run bundle identifiers; each test types the endpoint through the visible address control.
- Keep existing unit schemes unchanged. UI TestAction explicitly maps the endpoint without inheriting LaunchAction environment; macOS uses ad-hoc signing with no developer team, while tvOS simulator builds disable signing.
- Bound startup, builds/tests, logs and cleanup. Reserve owned process-group leaders until descendant TERM/KILL dispatch, then reap; never signal an unreserved reused group or erase an existing simulator. Stage diagnostics before deleting owned fixtures/state.
- Retain at most 32 MiB total and 20 MiB per xcresult. Extract failed-run summary/test/detail metadata even after Xcode exits 65. Independently export at most one named teardown AX text (512 KiB) and screenshot (2 MiB) from the first failed case by payload ID, excluding recordings and applying kernel file limits plus a shared deadline. Export errors never replace the original test failure.
- Set and verify system output mute before playback and leave it muted. Fixtures have no audio track; muted playback does not validate audible output.

## Client Coverage And Corrections
- Both clients cover isolated launch, real server connection, pagination, selecting entry 55 and actual playback progression. tvOS uses bounded remote focus/navigation, including materializing lazy rows after Load More disappears.
- macOS additionally checks pause/resume, approximate ten-second skips from stable paused baselines, measured 2x progression against a monotonic clock, uninterrupted natural completion, Forward at EOF and ordinary Resume afterward. It separately pauses before EOF and skips to the terminal position. Both EOF paths must expose finished state; Resume must rewind, advance again and preserve the selected speed without reloading the cache item.
- Normal macOS windows support a 900x560 minimum and 960x600 default, with transport/speed controls wrapping when needed. Tests require foreground, enabled/hittable targets and usable-display containment before clicks, preventing clicks into the Dock. The generic application's AX enabled flag is not an application-wide interaction gate.
- AX queries follow actual native roles: label/value for macOS text, identifier-based timeline/state lookup across element types, and radio-button speed selection. Expected titles, disconnected state, empty address, disabled initial Refresh, zero initial items and real timeline assertions remain mandatory.
- Shared AppCore distinguishes buffering from a user pause. Explicit pause cancels waiting autoplay; resuming preserves speed and invalidates stale asynchronous loads.
- Finished replay seeks to zero before playing, checks current player/item/interaction identity on completion, restarts progress reporting at zero and releases pending replay state on stop/replacement. Pausing or a stale/failed seek cannot restart an old player.
- Relative seeks clamp to known duration. Forward, zero or non-moving seeks after EOF keep the ended marker even when duration is unknown; backward movement away from EOF restores paused progress and resumes at the selected position.
- Seeking to EOF is not treated as proof of a natural-end notification. Confirm terminal seeks through their completion callback and current player/item/interaction identity, retaining the exact duration CMTime. A paused confirmed terminal position also enables rewind on Resume; failed, stale or superseded callbacks cannot finish a replacement item.

## Boundaries
- No saved credential profiles, Web cookies, public proxies, Bilibili login or internet video are used by ordinary CI. Private test material stays outside Git.
- Physical Apple TV, audible audio, real Bilibili/proxy long-running validation and control-stream watcher reconnect are separate workstreams. Installed iOS runtimes do not imply an iOS app target.
